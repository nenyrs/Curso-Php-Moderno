Super Globais do PHP

$_GET

O super global $_GET é um array associativo que armazena os dados enviados pela URL.

$_POST

O super global $_POST é um array associativo que armazena os dados enviados pela URL.

$_REQUEST

O super global $_REQUEST é um array associativo que armazena informações sobre o servidor e o ambiente em que o PHP está sendo executado.

$_COOKIE

O super global $_COOKIE é um array associativo que armazena informações sobre os cookies do usuário.

$_FILES

O super global $_FILES é um array associativo que armazena informações sobre arquivos enviados pela URL.

$_SESSION

O super global $_SESSION é um array associativo que armazena informações de sessão do usuário.

$_ENV

O super global $_ENV é um array associativo que armazena informações de ambiente do sistema.

$_SERVER

O super global $_SERVER é um array associativo que armazena informações sobre o servidor e o ambiente em que o PHP está sendo executado.

$GLOBALS

O super global $GLOBALS é um array associativo que armazena todas as variáveis globais do PHP.
